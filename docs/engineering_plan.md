## 7. 模型评价标准

### 7.1 评价维度

精度 / 稳健性 / 相对性 / 可解释性 / 业务对齐。

### 7.2 指标定义

预测在 `log1p` 空间训练，**评价前还原到原尺度**（`expm1` + Duan smearing 偏差校正）。

| 指标 | 公式 | 用途 |
|---|---|---|
| MAE | `mean(|y-ŷ|)` | 绝对误差 |
| RMSE | `sqrt(mean((y-ŷ)²))` | 惩罚大误差 |
| WMAE | `Σwᵢ|y-ŷ|/Σwᵢ`，节假日 `w=5` | **主指标（业务口径）** |
| WAPE | `Σ|y-ŷ|/Σ|y|` | 跨店可比 |
| sMAPE | `(2/n)Σ|y-ŷ|/(|y|+|ŷ|)` | 抗除零 |
| R²/Adj-R² | `1-SSres/SStot` | 解释力 |
| MASE | `MAE/MAE_naive(m=52)` | 时序基线，<1 优于朴素法 |

### 7.3 分层报告

全局合计 / 门店级分布（中位数、P90、最差门店）/ 节假日 vs 非节假日 / 分年份 / 三层模型横向对比。

### 7.4 统计模型验收

| 检查项 | 阈值 |
|---|---|
| VIF | < 5（宽松 < 10） |
| 系数显著性 | p < 0.05，95% CI |
| 系数方向稳定性 | ≥4/5 折符号一致 |
| Ljung-Box | p > 0.05 |
| Breusch-Pagan | 显著则用稳健标准误 |
| 增量贡献 | 加入因素后 Adj-R² 显著提升 |
| SHAP 一致性 | 与回归系数方向一致 |

### 7.5 通过门限（Gate）

1. **G1** 单店/簇模型 WMAE 相对 naive 季节基线下降 ≥ 15%。
2. **G2** 单店 WMAE 不劣于全局池化，且最差门店更优。
3. **G3** 5 折 WMAE 的 `std/mean < 15%`，无单年崩坏。
4. **G4** 训练/验证 WMAE 差距 < 20%（log1p 空间）。
5. **G5** ≥3 个因素通过“方向稳定 + 显著 + SHAP 一致”。
6. **G6** 节假日周 WMAE 单独达标。

> 绝对阈值（如单店 WMAPE ≤ 5~8%）待基线跑出后回填锁定。

## 12. 模型选型依据与算法原理

### 12.1 选型总原则：基线递进（Occam）

```
季节朴素(去年同周) → 门店均值 → Ridge
      → LightGBM / GradientBoosting → 三层结构对比
```

每增加一层复杂度，必须在滚动 CV 上证明 WMAE 有**显著**改善（Wilcoxon，p<0.05），否则回退到更简单模型。基线的作用是给出指标下界与参照系。

### 12.2 过拟合风险与各层推荐

| 层级 | 样本量 | 过拟合风险 | 首选 | 备选 | 不推荐 |
|---|---|---|---|---|---|
| A 全局池化 | 6435 | 低 | LightGBM / GradientBoosting | Ridge + 固定效应 | — |
| B DTW 簇 | ~600~2000 | 中 | Ridge | 浅层 LightGBM | — |
| C 单店 | **143**（首折约 70~100） | **高** | Ridge / ElasticNet | 浅层 LightGBM(`max_depth≤3`) | 深 RF、深 GBM |

**RandomForest 定位**：可在 A/B 层作候选；**不作单店主力**，因其默认无深度约束、且无法外推时间趋势。

**强正则 / 浅层含义**：限制模型容量（`max_depth`、`min_samples_leaf`、L1/L2 `lambda`），使有效参数远小于样本量（经验：单店特征数 ≤ 样本量的 1/5）。

### 12.3 算法原理

#### 12.3.1 全局池化（Pooling）与固定效应（Fixed Effects）

- **池化**：把 45 家店数据合并，只训练一个模型，共享全部参数。
- **问题**：门店量级差 8 倍，模型会把“门店规模”误当作因素影响。
- **固定效应**：给每家店一个专属截距。两种等价实现：
  - 哑变量：`ŷ = α + Σ_s β_s·1[store=s] + Xγ`
  - 组内去均值（within transform）：对每个变量减去该店均值 `x̃ = x - x̄_s`，消去 `β_s`。

  原理：门店特有、不随时间变化的因素（规模、选址、商圈）被截距吸收，`γ` 只反映**门店内部**的共同规律。属“去混杂”，与第 11 节清洗一脉相承。

#### 12.3.2 DTW 动态时间规整（Dynamic Time Warping）

衡量两条时间序列的形状相似度。欧氏距离要求**同时间点**对齐 `Σ(x_t - y_t)²`，对相位偏移极敏感；DTW 允许在时间轴上非线性拉伸/压缩对齐。

递推（代价矩阵 D，长度 n×m）：
```
D(i,j) = d(x_i, y_j) + min( D(i-1,j), D(i,j-1), D(i-1,j-1) )
DTW(X,Y) = D(n,m)
```
`d` 为点距离（常用 |x_i−y_j|）。对本项目：45 家店两两计算 → 45×45 距离矩阵 → 聚类。复杂度 O(n·m)，全矩阵 O(45² · 143²) ≈ 4×10⁷ 单元，**适合 C++ + OpenMP 并行加速**。

#### 12.3.3 肘部法（Elbow Method）

簇数 K 从 1 递增，计算 **簇内平方和 WCSS**：
```
WCSS(K) = Σ_{k=1..K} Σ_{x∈C_k} ||x - μ_k||²
```
WCSS 随 K 单调下降；取下降速度骤减的“肘点”为 K。优点快，缺点是拐点有时不清晰。

#### 12.3.4 轮廓系数（Silhouette Coefficient）

对每个点 i：`a(i)`=到同簇其他点平均距离，`b(i)`=到最近异簇平均距离，
```
s(i) = (b(i) - a(i)) / max(a(i), b(i))   ∈ [-1, 1]
```
越接近 1 越好。取全样本均值最大的 K。与肘部法结合**自动定簇数**（两者一致时最稳）。

#### 12.3.5 Ridge 岭回归

普通最小二乘 `β̂ = (XᵀX)⁻¹Xᵀy` 在特征共线（本项目 CPI/Unemployment 强共线）时方差爆炸。Ridge 加 L2 惩罚：
```
β̂ = argmin ||y - Xβ||² + λ||β||²  = (XᵀX + λI)⁻¹Xᵀy
```
`λ` 使矩阵可逆、系数收缩，显著抗过拟合；不置零系数，适合“都保留、但压低影响”的小样本场景。`λ` 用滚动 CV 选。

#### 12.3.6 RandomForest 随机森林

对数据做**有放回抽样（bootstrap）**建多棵决策树，每棵树分裂时只在随机特征子集里选最优分裂点，最后对结果**取平均**。
- 降方差：`Var(平均) = ρσ² + (1-ρ)σ²/B`，树间相关性 ρ 越低、树数 B 越多越稳。
- 抗噪声、无需调参；但**不能外推趋势**（叶子输出是训练均值），且默认深树在小样本上会记忆数据，OOB 误差在自相关序列上被低估。

#### 12.3.7 GradientBoosting 梯度提升

**串行**加树：每棵新树拟合当前模型的负梯度（残差方向），即函数空间的梯度下降。
```
F_m(x) = F_{m-1}(x) + ν · h_m(x)
```
`ν` 为学习率（收缩）。逐步纠错、拟合能力强；但串行训练慢、对超参敏感、无强正则时易过拟合。

#### 12.3.8 LightGBM

GBDT 的高效实现，三大优化：
- **直方图分箱**：连续特征离散为桶，分裂点搜索从 O(#样本) 降到 O(#桶)。
- **Leaf-wise 生长**：每次分裂增益最大的叶子（对比 XGBoost 的 level-wise），同样叶子数下损失更低——**但要配合 `max_depth`/`num_leaves` 防过拟合**。
- **GOSS + EFB**：单边梯度采样保留大梯度样本、互斥特征捆绑降维。

小样本上必须收紧 `num_leaves`、`min_data_in_leaf`、`lambda_l1/l2`，否则很易过拟合。

#### 12.3.9 季节性朴素基线（Seasonal Naive）

`ŷ_t = y_{t-52}`（去年同周）。零参数、无过拟合，是时间序列的**最低门槛**。MASE < 1 才说明模型优于它；G1 门限要求 WMAE 相对其下降 ≥ 15%。

### 12.4 选型结论

1. **先基线后复杂**：季节朴素 + Ridge 打底。
2. **单店**：Ridge/ElasticNet 为主，浅层 LightGBM 为辅；禁用深 RF。
3. **全局/簇级**：LightGBM 或 Ridge+固定效应。
4. **DTW 聚类**：肘部法 + 轮廓系数双判据自动定 K；距离矩阵交 C++ 加速。
5. **RF 仅作对照**，其价值在于提供“非线性但不过度调参”的中等复杂度参考点。

## 13. 验证策略详解

### 13.1 留出集 vs 交叉验证：两件事

| 概念 | 目的 | 使用频率 | 本项目对应 |
|---|---|---|---|
| 交叉验证 CV | 调参、选特征、模型对比 | 反复使用 | 5 折滚动原点 |
| 测试/留出集 | 无偏的最终成绩 | **全程只碰一次** | 末段最后 13 周 |

**纪律**：所有决策（调参/选型）只看 CV；测试集在定稿后跑一次出报告。若依据测试集回头改模型，它即被污染，不再是留出集。

### 13.2 K 折交叉验证

将数据切 K 份，轮流 K-1 份训练、1 份验证，重复 K 次后取平均：

```
fold1: [训练 训练 训练 训练][验]
fold2: [训练 训练 训练][验][训练]
fold3: [训练 训练][验][训练 训练]
fold4: [训练][验][训练 训练 训练]
fold5: [验][训练 训练 训练 训练]
指标 = mean ± std
```

优点：每个样本都当过一次验证，用满数据、估计更稳；`std` 反映稳健性（G3 门限）。前提：样本独立同分布。

### 13.3 时序必须用有序切分

| 方法 | 做法 | 时序可用 |
|---|---|---|
| 普通 K-fold（随机打乱） | 随机分 K 份 | ❌ 会泄漏未来 |
| **滚动原点 / TimeSeriesSplit** | 训练只含过去，验证取紧随其后一段并向前滚动 | ✅ |
| 扩展窗口 (expanding) | 每折训练集递增 | ✅ 本项目采用 |
| 滑动窗口 (sliding) | 训练窗口固定长度滑动 | ✅ 强调近期 |

### 13.4 嵌套 CV

若用同一批 CV 既调参又报成绩，会产生**乐观偏差**。严格做法：

- **外层 CV**：评估泛化性能；
- **内层 CV**：在每折训练集内调超参。

单店样本少时，内层固定少量候选、只报外层 `mean±std` 即可。

### 13.5 本项目落地

1. 5 折**扩展窗口**滚动 CV 调参/对比；
2. 末段最后 13 周作**最终留出**，仅终验一次；
3. 分层报告门店级分布与分年份诊断；
4. 全程无随机打乱、滞后特征只用过去值。

## 16. 基线实验结果与对“XGBoost 98%”的评估

### 16.1 实验设置

- 5 折扩展窗口滚动 CV（每折验证 13 周），末段最后 13 周留出终验；
- 特征：外生 5（Temperature/Fuel/CPI/Unemployment/Holiday）+ 时间 3 + 门店内滞后/滚动（lag1/2/4/52、roll mean/std 4/8/13）+ 门店哑变量；
- 目标 `log1p`，原尺度评价含 Duan smearing；
- 种子 42，线程 1。

### 16.2 结果（滚动 CV 总体）

| 模型 | WMAE | WAPE | RMSE | R² | vs 季节朴素 p 值 |
|---|---|---|---|---|---|
| **XGBoost** | **61087** | **0.0506** | 81769 | **0.9792** | 1.9e-12 ✅ |
| LightGBM | 62580 | 0.0511 | 82621 | 0.9788 | 7.1e-11 ✅ |
| 季节朴素 | 62770 | 0.0561 | 87540 | 0.9762 | — |
| Ridge 全局 | 100321 | 0.0719 | 133172 | 0.9449 | 8.0e-05 ✅(更差) |
| Ridge 单店 | 103936 | 0.0818 | 153409 | 0.9269 | 1.3e-20 ✅(更差) |
| 门店均值 | 106034 | 0.0885 | 167017 | 0.9134 | 1.3e-35 ✅(更差) |

末段留出：XGBoost WMAE 40717、WAPE 0.0351，同样最优。

### 16.3 结论

1. **梯度提升确实最优**，但相对季节朴素的提升有限（WMAE −2.7%），并非质的飞跃。
2. **季节朴素已是强基线**（R² 0.976），说明销售额主要由“门店规模 + 年度季节性”决定。
3. **仅靠宏观变量 + 时间的 Ridge 反而更差**，滞后/滚动特征才是提升关键。
4. 单店 Ridge 未超过全局，印证单店 143 样本下正则化模型的容量不足。

### 16.4 “XGBoost 准确率 98%”怎么看

**结论：数字可复现，但被误读，且评价口径有硬伤。**

已在 `src/forum_leak_audit.py` 复现论坛方法（同特征、同 XGBoost 参数），得到 **R²=0.9838**，与其 **0.9849** 基本一致。但其结论存在四个问题：

1. **概念错误**：回归没有“准确率”。0.98 是 R²；本数据**季节朴素单模型 R² 就达 0.976**，门店规模解释约 94% 方差，R² 天然很高。
2. **随机切分导致虚高**：论坛用 `train_test_split(random_state=0)`。受控对照（下表）显示，改用时间切分后 R² 从 0.984 降到 0.979，差额来自相邻周信息插值。
3. **目标编码泄漏影响很小（但确实违规）**：`store_sales_encoded` 在全量数据上计算，理论上泄漏测试集目标；但每店 143 个观测使单人改动可忽略，实测仅差 0.0001。
4. **还原公式写错**：`y_pred_actual = np.exp2(y_pred_log)` 用了 **2 的指数**，应为 `np.expm1`。因此“平均误差 $7.26”完全失真——预测值越大约误差越小，属 bug 而非精度。

**受控对照（复现结果，log1p 空间）**

| 切分方式 | 目标编码 | R² | RMSE(log) |
|---|---|---|---|
| 随机切分（泄漏） | 全量（泄漏） | 0.9838 | 0.0745 |
| 随机切分（泄漏） | 训练集（正确） | 0.9839 | 0.0741 |
| **时间切分（正确）** | 全量（泄漏） | 0.9788 | 0.0833 |
| **时间切分（正确）** | 训练集（正确） | 0.9789 | 0.0830 |

**核心判断**：随机切分是虚高主因；目标编码泄漏因样本充足影响极小。论坛真实水平 ≈ **R² 0.979**，与本项目无泄漏流水线（0.9792）持平，**并非 XGBoost 带来了 98%**，而是门店规模 + 强季节性使 R² 天然很高。

**其他代码问题**：`to_drop` 写成小写 `'store'`（无此列）导致 `Store` 以序数形式保留；`weekend` 特征因数据全为周五而恒为 0；CELL 35 的 `TimeSeriesSplit` 仍使用全量编码后的 X，CV 结果同样被污染；缺少强基线对比与偏差校正。

**建议**：判断模型优劣请用**无泄漏滚动 CV + WMAE/WAPE/MASE + 相对季节朴素/门店均值的显著性检验**。本项目 XGBoost 的 WAPE 仅 0.051，仍有约 5% 误差，绝非“98% 全对”。

## 19. C++ 加速（P3）

工具链：GCC 16.2 / CMake 4.3 / pybind11 3.1 / OpenMP。

### 19.1 模块

`walmart_cpp`（`cpp/src/walmart_core.cpp` + `bindings.cpp`）暴露两个接口：

| 接口 | 说明 | 并行策略 |
|---|---|---|
| `dtw_distance_matrix(series, band, threads)` | 45×45 DTW 距离矩阵 | OpenMP 按行并行（`schedule(dynamic)`） |
| `ridge_grid_search(X, y, train_idx, val_idx, weights, alphas, threads)` | Ridge alpha 搜索（闭式解） | 预计算每折 Gram 矩阵，按 alpha 并行 |

Ridge 闭式解：`β = (XᵀX + αI)⁻¹Xᵀy`；`XᵀX`/`Xᵀy` 与 alpha 无关，**每折只算一次**，再对 25 个 alpha 并行求解（高斯消元 + 部分主元）。

### 19.2 基准结果（`python src/bench_cpp.py`）

| 任务 | Python | C++ | 加速比 | 结果一致性 |
|---|---|---|---|---|
| DTW 45×45 距离矩阵 | 15.0s | 0.012s | **≈1288×** | 逐位相同（max diff 0.0） |
| Ridge alpha 搜索（25 α × 5 折） | 0.578s | 0.045s | **13×** | max diff 1.8e-12，最优 α 一致（0.00316） |

### 19.3 构建

```bash
cd cpp
cmake -B build -Dpybind11_DIR=$(python3 -m pybind11 --cmakedir) -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
# 产物自动输出到 src/walmart_cpp.*.so
```

`three_tier.py` 中的纯 Python `compute_dtw_matrix` 可替换为 `walmart_cpp.dtw_distance_matrix`（接口一致），DTW 耗时从 15s 降至毫秒级。

## 20. 分层评估与极端门店诊断（P4）

运行 `python src/stratified_eval.py --tag stratified`，输出至 `reports/`。

### 20.1 按年份 WAPE（验证段覆盖 2011-08 起，故无 2010）

| 层级 | 2011 | 2012 |
|---|---|---|
| **B 簇级** | **0.0566** | **0.0421** |
| A 全局 | 0.0587 | 0.0463 |
| C 单店 | 0.0748 | 0.0467 |
| 季节朴素 | 0.0587 | 0.0547 |

2011 明显更难（经济/结构扰动），但 **B 在两年都最优**，结论不依赖单一年份。

### 20.2 按节假日 WAPE

| 层级 | 平常周 | 节假日周 |
|---|---|---|
| B 簇级 | **0.0447** | 0.0754 |
| A 全局 | 0.0484 | 0.0748 |
| C 单店 | 0.0542 | 0.0831 |
| 季节朴素 | 0.0553 | **0.0647** |

**关键发现：节假日周是所有 ML 模型的弱项**，甚至**劣于季节朴素**（0.075 vs 0.065）。原因是节假日尖峰稀疏且类型不同（超级碗/感恩节/圣诞），ML 模型被平常周主导。**改进方向：节假日专用模型或节假日特征增强**。

### 20.3 按温度分段 WAPE

| 层级 | <32F | 32-50F | 50-70F | 70-90F | >90F |
|---|---|---|---|---|---|
| B 簇级 | 0.0592 | 0.0637 | **0.0443** | **0.0388** | 0.0387 |
| 季节朴素 | **0.0464** | **0.0594** | 0.0543 | 0.0586 | **0.0403** |

B 在温和/高温段最好；极冷段（<50F）季节朴素更稳（门店动量在冬季扰动大）。

### 20.4 残差诊断

| 层级 | 残差均值 | 残差std | Ljung-Box p | Breusch-Pagan p | 自相关通过 | 同方差通过 |
|---|---|---|---|---|---|---|
| B 簇级 | 5951 | 77547 | **0.926** | 2.8e-63 | ✅ | ❌ |
| A 全局 | 2290 | 81737 | 0.478 | 2.3e-50 | ✅ | ❌ |
| C 单店 | 16246 | 102626 | **0.0047** | 1.2e-46 | ❌ | ❌ |
| 季节朴素 | 23056 | 84450 | 0.880 | 3.4e-63 | ✅ | ❌ |

- **B/A 残差无自相关**（Ljung-Box p>0.05）→ 结构被充分提取；
- **C 单店残差存在自相关**（p=0.005）→ 过拟合导致结构残留；
- 异方差普遍存在（跨门店量级差异所致，属预期）。

### 20.5 极端门店诊断（B 簇级，最差 10）

| Store | WAPE | mean_sales | lag1 自相关 |
|---|---|---|---|
| 35 | 0.0711 | 919,725 | 0.606 |
| 18 | 0.0700 | 1,084,718 | 0.442 |
| 7 | 0.0661 | 570,617 | 0.753 |
| 15 | 0.0614 | 623,313 | 0.525 |
| 24 | 0.0612 | 1,356,755 | 0.360 |
| 28 | 0.0610 | 1,323,522 | **0.149** |

- 最难预测的门店集中在**簇 3**（中型店），且 **lag1 自相关偏低**（store 28 仅 0.149，24 为 0.360）→ **自身动量弱则模型更差**；
- 大店虽误差金额大，但 WAPE 未必差（如 store 14 WAPE 0.056）。

### 20.6 结论与改进方向

1. B 簇级在年份/温度多数分层稳健，**推荐为主模型**；
2. **节假日是主要短板**，需节假日专用建模或加权；
3. 极端门店由**低自相关**导致，可引入更多外生/邻店信息；
4. C 单店应淘汰（残差自相关 + 整体最差）。
